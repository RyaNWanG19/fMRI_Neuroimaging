## Figure interpretation

- Pairwise count matrices: diagonal values are category totals; off-diagonal values count regions significant in both categories. A region can contribute to several pairs.
- Jaccard matrices: intersection divided by union. Zero means no overlap and one means identical sets. This normalizes for differing set sizes.
- Exact-combination bar charts: every region contributes to exactly one row. “body + faces” excludes places and tools.
- Breadth chart: regions significant in exactly zero, one, two, three or four categories.

The original Monte Carlo precision qualification still applies to the saved classifications. No bootstrap stability or overlap significance analysis is claimed. Smaller sets can have lower Jaccard overlap due to thresholding and power. This does not independently establish greater biological specificity or better fit.
